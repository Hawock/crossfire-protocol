# 🚀 Crossfire Protocol
_A real-time strategy prototype by YKJ Interactive_

## 🎮 About the Game
Crossfire Protocol is a modern reimagining of classic RTS mechanics (inspired by **Metal Marines** and other 90s strategy games).  
Players build their bases on isolated islands, manage resources and energy, and unleash rockets and dropships in tactical battles.  

Key Features (planned):
- 🏗️ Base building with resource and energy management  
- 💥 Tactical rocket strikes and drop assaults  
- 🌫️ Fog of war with outdated intel mechanics  
- ⚔️ Different unit archetypes (infantry types, upgrades, future vehicles)  
- 🌍 PC-first release (Steam target)
